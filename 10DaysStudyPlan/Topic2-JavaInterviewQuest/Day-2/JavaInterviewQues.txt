Java Interview Questions (Detailed Preferred Answers)

1. What is a constant in Java and how can you declare a constant variable?
Answer:
A constant in Java is a variable whose value cannot be changed once assigned.

Constants are used when a fixed value is needed throughout the program, such as:
PI value
Tax rate
Maximum size
Company code
Declaration of Constant:
In Java, constants are declared using the final keyword.
final int MAX = 100;
final double PI = 3.14159;
Naming Convention:
Constants are usually written in UPPERCASE with underscores.
final int MAX_USERS = 500;
Benefits:
Prevent accidental modification
Improves readability
Easy maintenance
Interview Smart Line:
“A constant is an unchangeable variable declared using final keyword.”

2. What is the purpose of the final keyword in Java constants?
Answer:
The final keyword is used to make a variable constant.

Once a value is assigned to a final variable, it cannot be reassigned.

final int AGE = 25;
// AGE = 30;   Error
Uses of final:
With Variables:

Makes variable constant.

With Methods:

Prevents method overriding.

With Classes:

Prevents inheritance.

final class Demo { }
Interview Smart Line:

“In constants, final ensures that the value remains fixed after initialization.”

3.What are bitwise operators in Java and where are they used?
Answer:
Bitwise operators perform operations on individual bits of integer data.

They work at binary level.

Bitwise Operators in Java:
Operator	Meaning
&	Bitwise AND
`	`
^	Bitwise XOR
~	Bitwise NOT
<<	Left Shift
>>	Right Shift
>>>	Unsigned Right Shift
Example:
int a = 5;   //0101
int b = 3;   //0011
System.out.println(a & b); //1
Used In:
Flags and masks
Encryption
Performance optimization
Low-level programming
Hardware control
Interview Smart Line:

“Bitwise operators manipulate data bit by bit and are commonly used in optimized and low-level operations.”

4. Explain the difference between bitwise AND (&) and logical AND (&&) operators.
Answer:

Basis			&		   	     &&
Type		Bitwise AND / Boolean AND	Logical AND
Works On	Integers and booleans		Boolean only
Evaluation	Evaluates both operands		Short-circuit evaluation
Use		Bit operations			Conditions

Example:
if(a>5 & b<10)
Both conditions checked.
if(a>5 && b<10)
If first is false, second is not checked.

Interview Smart Line:

“& checks both sides always, while && stops early if first condition is false.”

5. What is the purpose of the main() method in Java?
Answer:
The main() method is the entry point of a Java application.
When JVM starts a Java program, it looks for the main() method and begins execution from there.
public static void main(String[] args)
{
   System.out.println("Hello");
}
Purpose:
Starts program execution
Receives command line arguments
Controls initial flow of program
Interview Smart Line:
“The JVM calls main() first, so it acts as the starting point of a Java application.”

6. Why is the main() method declared as public static void main(String[] args)?

Answer:

public static void main(String[] args)
Meaning of Each Keyword:
public

JVM must access it from outside class.

static

No object required. JVM can call directly using class name.

void

Returns no value.

main

Special method name recognized by JVM.

String[] args

Stores command line arguments.

Interview Smart Line:

“It is declared public so JVM can access it, static so object is not needed, 
void because nothing is returned, and String[] args to accept inputs.”

7. Can a Java program run without the main() method? Explain.
Answer:

Yes and No.
Normal Java Application:

No. JVM needs main() method to start execution.

Example:0;
class Test
{
}

Cannot run normally.

But In Some Cases:
Static blocks (older versions behavior changed)
Applets (obsolete)
Servlet frameworks
JUnit tests
Spring Boot applications use framework bootstrap methods
Interview Best Answer:

“For a standard standalone Java application, main() is required because 
JVM starts execution from it. Some frameworks manage startup differently.”

8. What are command line arguments in Java and how are they passed to a program?
Answer:
Command line arguments are values passed while running the program from terminal.

They are stored in:

String[] args
Example:
java Demo John 25

Here:

John
25

are command line arguments.

Use Cases:
Username input
File path
Config values

9. How do you access command line arguments inside the main() method?
Answer:
Arguments are accessed using array indexing.

public static void main(String[] args)
{
   System.out.println(args[0]);
   System.out.println(args[1]);
}
Run:
java Demo Hello Java
Output:
Hello
Java
Important:

Check length to avoid error:

if(args.length > 0)
Interview Smart Line:

“Command line arguments are stored as strings in args[] and accessed by index.”

10. What is the Scanner class in Java and why is it used?
Answer:
Scanner is a class from Java utility package used to take input from user.

import java.util.Scanner;
Example:
Scanner sc = new Scanner(System.in);
int age = sc.nextInt();
String name = sc.next();
Used For Taking:
Integer input
String input
Decimal input
Character (indirectly)
Common Methods:
Method	Use
nextInt()	Integer
nextDouble()	Decimal
next()		Single word
nextLine()	Full line
nextBoolean()	Boolean
Why Used?
Before Scanner, input handling was complex. Scanner makes it easy.
Interview Smart Line:

“Scanner is used for reading user input from keyboard in a simple and structured way.”
