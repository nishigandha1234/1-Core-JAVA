DAY-1 Java Interview Perspective Answers

1. What is Java and why is it platform independent?
Answer:
Java is a high-level, object-oriented programming language used to build web, desktop, mobile, and enterprise applications. 
It is platform independent because Java code is compiled into bytecode, which runs on the JVM (Java Virtual Machine). 
So the same program can run on any system that has a JVM installed.

3. What is JVM and what is its role?
Answer:
JVM stands for Java Virtual Machine. It is responsible for running Java bytecode on different operating systems.
It converts bytecode into machine code and provides memory management, garbage collection, and security.

4. What is JRE and why is it required?
Answer:
JRE stands for Java Runtime Environment. It contains JVM and required libraries to run Java applications. 
It is required when we want to execute Java programs.

5. What is JDK and how is it different from JRE?
Answer:
JDK stands for Java Development Kit. It is used for developing Java programs.
It contains:
JRE
JVM
Compiler (javac)
Debugging tools
Difference:
JDK is for development and execution, while JRE is only for execution.

6. What is Bytecode in Java?
Answer:
Bytecode is the intermediate code generated after compiling a .java file using javac. It is stored in the .class file and executed by JVM.

7. Differentiate between JDK, JRE, and JVM.
Answer:

10. Explain Write Once Run Anywhere.
Answer:
Write Once Run Anywhere means Java code is written once and can run on any platform without changing the code because Java uses bytecode and JVM.
